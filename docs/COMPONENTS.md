# NezumiOS Components

## Host

Components that belong to the base operating system:

- Ubuntu base system
- Linux kernel
- Hardware support
- NVIDIA drivers
- NVIDIA Container Toolkit
- Docker Engine
- Docker Compose
- Networking
- Storage
- System utilities

## AI Runtime

Core software used to provide AI capabilities:

- Ollama
- OpenClaw

## AI Workloads

Optional workloads managed independently from the host:

- ComfyUI
- FluxGym
- Telegram bots
- Other AI services

## Companion System

Future components:

- Companion runtime
- Companion manager
- Companion packages
- Companion registry

## User Interface

Future components:

- Companion-first interface
- Voice interaction
- Application launcher
- System controls
- Traditional/fallback desktop access
